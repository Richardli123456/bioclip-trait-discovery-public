# Independent colour review

The scoring package is prepared and independent results are pending. Reviewers see a single generated image at a time, record whether one animal is clearly visible, and identify noticeable body colours. The planned comparison covers feature addition, removal and matched random controls.

The study coordinator distributes the offline scoring page privately so reviewers can complete it before seeing labelled gallery examples. The public repository contains the research walkthrough and aggregate experimental findings. [Experiment index](../README.md)
